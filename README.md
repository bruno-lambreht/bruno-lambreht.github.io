# bruno-lambreht.github.io

Personal portfolio website — Bruno E. Lambreht.
Engineering at the intersection of **Economics** and **Technology**.

## Design Philosophy

Engineered under the intersection of three technical design systems:

- **Vercel (Structure & Precision):** Strict hairline grid system, disciplined typographic hierarchy (tight negative letter-spacing on display headers, uppercase mono eyebrows), restrained monochrome palette, generous negative space.
- **Raycast (Personality & Micro-details):** Continuous dark canvas ladder (`#07080a` → `#0d0e12` → `#13141a`), subtle 1px hairlines, Inter font with `ss03` stylistic alternates, high-contrast white primary CTA pill, keyboard and spec-sheet cues.
- **Ollama (Technical Simplicity):** Documentation/README aesthetic, honesty over decoration, architecture flows and pipeline specs as first-class content, zero bloated visual artifacts.

## Technical Highlights

- **Zero Runtime Framework Overhead:** 100% native CSS with CSS Custom Properties (Design Tokens) — no Tailwind CDN script or runtime parser.
- **Zero Heavy Webfont CDNs:** Replaced FontAwesome CDN with semantic typography, vector glyphs, and inline SVGs for instant rendering and zero layout shift.
- **Instant Load:** Removed artificial loader delays, floating parallax blobs, and heavy glassmorphism filters.
- **Bilingual Engine (EN / PT-BR):** Zero-dependency vanilla JavaScript translation system with persistent local state (`localStorage`) and instant language switching.
- **Full Responsive & Accessible Layout:** Mobile-first architecture, fluid typography via CSS `clamp()`, semantic HTML5 landmarks, visible focus states, and `prefers-reduced-motion` compliance.
