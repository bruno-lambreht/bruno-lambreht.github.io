# bruno-lambreht.github.io

Personal portfolio website — built with HTML5, Tailwind CSS (CDN), and vanilla JavaScript.

## Features

- **Dark mode** modern design with glassmorphism and gradient accents
- **EN/PT-BR toggle** — instant language switch without page reload
- **Responsive** — mobile-first layout with hamburger menu
- **Sections** — Hero, About, Skills, Projects, Contact
- **SEO** — Open Graph and Twitter Card meta tags
- **Page transition** — animated loading screen
- **Parallax** — background blobs react to scroll

## Stack

- HTML5 Semantic
- Tailwind CSS (CDN)
- JavaScript (Vanilla)
- FontAwesome (CDN)
- Google Fonts (Inter, JetBrains Mono)
